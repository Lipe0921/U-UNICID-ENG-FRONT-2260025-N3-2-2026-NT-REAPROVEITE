# 🍏 Reaproveite

> Projeto desenvolvido por estudantes de Engenharia de Software da UNICID para promover o aproveitamento integral dos alimentos, o combate ao desperdício e a preservação ambiental.

**🌐 Site publicado:** https://reaproveite.up.railway.app

**📦 Repositório:** https://github.com/Lipe0921/U-UNICID-ENG-FRONT-2260025-N3-2-2026-NT-REAPROVEITE

---

## 🎯 Objetivos

**Geral:** criar um portal web educativo, intuitivo e acessível que oriente o público sobre o aproveitamento integral dos alimentos, a redução de despesas e a proteção ao meio ambiente.

**Específicos:**
1. Disponibilizar guias práticos e receitas sustentáveis (cascas, talos, sementes e folhas).
2. Aplicar acessibilidade digital: HTML5 semântico, contraste, navegação por teclado, `alt` e ARIA.
3. Disponibilizar formulário de contato com validação em JavaScript, mensagens de erro e rascunho salvo no navegador.
4. Elaborar um comparativo de hospedagem e domínio (ver `orcamento_hospedagem.html`).
5. Validar o HTML5 e o CSS3 conforme o W3C.

## 🗺️ Estrutura do site (10 páginas)

| Página | Conteúdo |
|---|---|
| `index.html` | Apresentação do tema e benefícios |

## 🛠️ Tecnologias

- **HTML5** semântico, com `lang="pt-BR"`.
- **CSS3** responsivo (Flexbox e media queries), sem frameworks.
- **JavaScript** vanilla: validação, `localStorage`, menu e FAQ.
- **Git e GitHub** para versionamento e deploy.
- **Railway** para hospedagem, com deploy automático a cada commit.
- **Validadores:** W3C Validator (HTML e CSS) e html-validate.

## ▶️ Como rodar localmente

1. Clone o repositório: `git clone https://github.com/Lipe0921/U-UNICID-ENG-FRONT-2260025-N3-2-2026-NT-REAPROVEITE.git`
2. Abra `index.html` no navegador, ou use a extensão **Live Server** no VS Code.

Não há dependências para instalar.
